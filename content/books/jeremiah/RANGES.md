# Jeremiah verse ranges (WEB)

Proposed draft plan: 52 chapters, 127 ranges.

Paths: `content/books/jeremiah/<ch>/<start>-<end>.json` (hyphens in filenames; en-dashes in display titles).

Draft only. No build, push, deploy, landing update, sitemap change, or indexed-set addition.
AdSense is not approved yet: these books stay noindex and out of the sitemap.
A `_draft` marker in this book folder keeps the book out of a default site build until a later local-build / publish step.

Chapter endings verified from the official eBible.org WEB numbered chapter HTML, not inferred from array length.
Official counts match `en_web.json` for this book (no numbering gaps).

English/WEB numbering: Jeremiah 9:1 is Hebrew 8:23, and 9:2–26 is Hebrew 9:1–25. Preserve WEB verse numbers. Some Greek traditions place the oracles against the nations (English chapters 46–51) after 25:13 and in a different order. This site follows the WEB/English order. Note that difference only as a hedged observation where it helps a reader; do not make manuscript claims or treat either order as a theological fork.
